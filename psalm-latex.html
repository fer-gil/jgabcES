Psalm LaTeX / LilyPond Formatter

Example: 2,2,2,1 means lines 1–3 get two preparatory syllables, line 4 gets one. The pattern restarts in each stanza.

Blank line = new stanza. Optional override: 0| text, 1| text, etc.
Use ~ for a manual sinalefa, for example nombre~invoca.
Use † for a manual flex; the final accent is bold and everything after it is underlined.
